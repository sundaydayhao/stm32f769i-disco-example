# STM32F769I-DISCO Example

This repository contains a STM32CubeMX-generated example project for the
STM32F769I-DISCO board, using CMake as the build system.

## Contents

- `stm32f769i-disco-example.ioc`: STM32CubeMX project file
- `Core/`: application source generated by STM32CubeMX
- `Drivers/`: CMSIS and STM32 HAL drivers
- `Middlewares/`: middleware used by the generated project
- `cmake/`: CMake toolchain and STM32CubeMX integration files

## Toolchain

The project was verified locally with:

- CMake
- Ninja
- Arm GNU toolchain: `arm-none-eabi-gcc`

The local toolchain path used during setup is:

```powershell
C:\Users\hazh\.local\toolchains\arm-none-eabi-gcc-15.2.1-1.1\bin
```

## Build

From PowerShell:

```powershell
$env:Path='C:\Users\hazh\.local\toolchains\arm-none-eabi-gcc-15.2.1-1.1\bin;' + $env:Path
cmake --preset Debug
cmake --build --preset Debug
```

Release build:

```powershell
$env:Path='C:\Users\hazh\.local\toolchains\arm-none-eabi-gcc-15.2.1-1.1\bin;' + $env:Path
cmake --preset Release
cmake --build --preset Release
```

Build outputs are generated under `build/` and are intentionally ignored by Git.
